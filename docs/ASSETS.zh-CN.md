# 资源、默认效果与背景恢复

[返回首页](../README.md)

公开源码与私人电视上的既有资源分开处理。源码默认使用深蓝程序背景、系统字体、通用图标和空旧图库；本轮只增加一张来源已经核验的可选内置 CC0 照片。

## 蓝境实际应用图标

本轮已安装 3.3.2 使用的应用图标来源为 [Android vector XML](../app/res/drawable/icon.xml)。[可复用 SVG](../assets/bluehome-app-icon.svg) 按该 XML 的原路径与颜色精确导出，画布为 512 × 512，`viewBox="0 0 48 48"`；没有另行改稿。

XML 与导出的 SVG 属于本次原创蓝境标识，适用 [MIT](../LICENSE)，署名 Bluehome contributors。首页已使用该实际应用图标。

## 3.3.2 背景选择与恢复

本轮增加固定内置照片的选择及“恢复先前背景模式”。这不是通用外部图片导入，也不接受任意 URL、路径或程序。入口与格式安全要求见 [安全边界](SECURITY.zh-CN.md)。

恢复操作返回选择 Hidden Lake 之前的背景来源／模式，**不承诺恢复上一张精确照片**。轮换策略、缓存状态或缺失资产都可能让实际图片不同；没有可用图片时保留当前可用背景或退回程序背景。它也不是系统默认桌面、应用数据或电视网络设置的恢复操作。

公开源码默认深蓝背景。私人设备覆盖包可能保留旧壁纸、图标或配置，仅用于该设备，并不因此获得公开分发许可。

## 没有随源码迁入的内容

| 内容 | 公开源码行为 |
| --- | --- |
| Noto 字体文件 | 回退系统 sans-serif-light，中文字形由系统决定 |
| 旧白色／品牌 PNG 图标 | 使用代码绘制的通用四宫格 |
| 30 张旧 Wallhaven 图片及原清单 | 不随源码分发；旧图库为空 |
| 其他旧摄影背景 | 不分发；默认程序背景 |
| 真实天气位置、种子、偏好与缓存 | 不分发；天气默认不请求，首次时间可能占位 |
| 旧公共 CA 资产 | 不分发；使用系统验证，旧系统在线兼容性可能下降 |
| 私人设备截图与构建／抓取日志 | 不迁入；真实新截图单独检查后再发布 |

`WaveView` 保留在源码中，当前主界面没有启用它。新增截图必须来自真实设备画面，标注版本和本地素材配置；不以品牌图、照片拼接或概念图替代。
