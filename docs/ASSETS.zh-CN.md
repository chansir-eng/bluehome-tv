# 资源与行为差异

[返回首页](../README.md)

本候选没有旧工程的照片、字体、图标 PNG、天气配置或证书资产。发布源码无需等待它们全部获授权。

| 未迁入内容 | 既有代码回退 | 限制 |
| --- | --- | --- |
| Noto 字体文件 | 系统 sans-serif-light | 中文字形取决于系统 |
| 所有白色图标 PNG | 代码绘制通用四宫格 | 应用图标变为同一通用样式 |
| 摄影背景 | 深蓝程序背景 | 不是原有摄影/模糊效果 |
| 30 图离线图库 | 原创空清单，保留当前背景 | 不展示或轮换旧壁纸 |
| 真实 weather-location.json 与种子 | 不请求天气 | 新安装可能无可信时间 floor，时间显示占位 |
| 可选公共根 CA 文件 | 系统证书验证 | 旧系统在线兼容性可能下降；不能通过关闭校验补救 |

`WallpaperSettingsActivity` 当前未在 Manifest 声明，`WaveView` 当前未启用；保留源码便于后续维护，不宣传这些入口已可用。

新 Android vector、应用名资源与空图库为本次原创生成。SVG 封面和标识也是原创品牌提案，不是电视截图。

两张 CC0 摄影作品在独立素材准备目录处理，不自动加入本源码包或 APK；需要完成下载、元数据清理和实际像素/电视画面核验后再做资源变更。图片许可应独立保留来源与作者，不与代码 MIT 混写。
