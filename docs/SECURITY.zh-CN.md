## 当前入口约束

- 本轮 `BuiltinWallpaperActivity` 为 `exported=false`，由蓝境内部可见操作进入；已验证外部显式启动被系统以 Permission Denial／not exported 拒绝。
- 选择只接受代码中定义的固定枚举／内置资源，未知值拒绝或回退。
- 不接收任意 URL、外部路径、程序、命令或可转发的 Intent；不把输入解释为可执行内容。
- 恢复先前模式只处理应用保存的背景状态，不更改系统默认桌面、网络、其他应用或账户。
- 内置图片解码失败时保留可用背景或回退程序背景，不能关闭证书验证或放宽输入边界补救。

这不是通用图片导入功能。不承诺外部文件复制到共享目录便自动生效，也不应通过临时导出组件或直接改写私有数据代替正常入口。

## 未来静态图片导入要求

如以后实现导入，应单独设计并验证以下边界，不能直接开放任意路径或 URL：

1. 只处理受支持的静态位图。检查真实格式并完成受限解码，扩展名与 MIME 不能单独作为可信依据；拒绝脚本、HTML、SVG、程序包及其他可执行内容。
2. 读取前限制文件字节数，解码前检查尺寸和总像素；按采样、内存预算和后台任务处理，防止过大图片阻塞或耗尽旧电视内存。
3. 使用系统授予的明确读取权限；只把通过检查的内容复制到应用私有存储，采用应用生成的安全文件名与原子替换。
4. 不把原始文件名或外部路径作为内部目标路径；拒绝绝对路径、路径分隔符和目录穿越，确保实际目标仍位于允许目录。
5. 成功解码与落盘后才提交状态，保留可恢复的先前模式；失败时不丢弃当前可用背景。图片内容始终不得执行。
6. 检查 EXIF／XMP、位置、账号、水印及公开权限；导入到私人设备不等于授权公开到仓库。

文件大小、像素与内存的具体上限应由实现和目标设备测试决定；当前不虚构已验证阈值。

## Android 5.1 的剩余限制

本项目仍以旧 API 配置和厂商系统入口为基础。应用内固定输入与私有存储不能修补系统／图像解码器缺陷，也不能保证第三方服务、证书库或厂商组件安全与可用。

不要求 root、放宽组件导出、关闭 TLS 校验、清除应用数据或改变电视网络来完成背景功能。调试与安装权限、签名连续性、资源内存和不同遥控器行为需要在目标设备分别核验。

请勿在公开问题中贴出密钥、账号、精确位置、设备身份、内网信息或原始诊断日志。可先报告版本、可复现操作及不含秘密的现象描述。
