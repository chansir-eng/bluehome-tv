# 隐私检查与配置

仅从明确文件清单复制源码，不迁入旧 `.git`、用户偏好、账号数据、签名目录、安装包、日志或实验资料。原项目保持不变，没有读取被排除的凭据文件来做扫描。

候选检查覆盖 14 Java、Manifest、XML、构建脚本、文档、示例与原创 SVG，检查硬编码凭据、私有地址、邮箱、IP/MAC、本机用户路径和带认证信息的 URL。检查范围和残余限制会记录在本地清单；不承诺绝对零泄漏。

## API 与运行时配置

源码中 API key 的格式检查、隐藏输入和本地偏好读取是功能逻辑，不是实际凭据。候选不包含任何真实 key、偏好或缓存，也没有创建或登录账号。未核实的备用 API 服务已从候选移除；可选在线壁纸只允许官方主机。

天气默认没有位置配置，因而不会请求天气接口；保留的 `config-examples/weather-location.example.json` 使用 dummy 数值，不代表任何人的位置，也不会进入 APK。不要把真实城市/坐标、天气种子、账号、私有接口或认证参数提交到仓库。

新安装无既有偏好时默认使用离线背景逻辑。现有安装的运行时偏好可能不同，候选没有读取或清除它们，也没有安装到设备上。

## 资源与历史

旧壁纸、字体、PNG 图标、真实天气配置、公共 CA 文件和截图没有迁入。新增素材应单独核验版权、隐私、EXIF/XMP、二维码、水印及实际展示范围；代码许可不覆盖图片许可。

没有迁入旧 Git 历史，初次发布只加入明确白名单。新增文件或拟发布历史需要重新检查。不要直接上传整个工作目录，也不要公开本地构建日志。
