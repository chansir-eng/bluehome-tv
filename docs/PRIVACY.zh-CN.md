## API 与运行时配置

源码中的 API key 格式检查、隐藏输入和偏好读取属于功能逻辑，不是实际凭据。仓库不包含真实 Key、账号、偏好或缓存。未核实的备用服务已从干净候选移除，可选在线客户端仍受官方主机白名单限制。

天气没有真实位置配置，默认不请求天气；`config-examples/weather-location.example.json` 使用 dummy 数值，不进入 APK。不要提交真实城市／坐标、天气种子、私人接口或认证参数。

3.3.2 的内置照片选择不需要账号、API Key 或网络访问。公开源码默认深蓝程序背景；既有电视运行时配置可能不同，不能将私人安装包或设备偏好迁入公开仓库。
